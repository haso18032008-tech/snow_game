# CLAUDE.md

Снежная ферма — браузерная игра (Three.js, без сборщика) + небольшой Django-бэкенд для аккаунтов,
облачного сохранения и таблицы лидеров. Бывшая часть Финстата, теперь самостоятельный проект.
Деплой на Render.

## Команды

- Запуск локально: `python manage.py runserver` (SQLite, переменные окружения не нужны)
- Проверка перед сдачей: `python manage.py check`, затем функциональная проверка через
  `python manage.py shell` с `django.test.Client` — отдельного набора тестов нет
- После изменения моделей: `makemigrations` + `migrate`
- `DATABASE_URL` переключает SQLite → PostgreSQL. База у игры СВОЯ, не база Финстата

## Структура

- `config/` — настройки (один файл на локаль и прод, прод включается переменными окружения)
- `snow_game/` — единственное приложение: модель `GameSave`, API (`/api/save/`, `/api/leaderboard/`),
  админка, команды `ensure_admin` и `import_players`
- `snow_game/static/snow_game/js/` — клиент игры; порядок подключения скриптов важен (см. `index.html`)
- `templates/allauth/layouts/base.html` — единственный наш шаблон входа/регистрации, остальное из allauth

## Конвенции

- Комментарии в коде — на русском, объясняют «почему так», а не «что делает строка»
- Аккаунты — только через allauth (логин/пароль + Google). Своих форм регистрации не писать
- Всё серверное привязано к `request.user`; чужое сохранение достать нельзя
- Клиент присылает состояние — на сервере оно только чистится в `clean_state()`, ему не доверяют
- Игра должна работать без входа и без сети (localStorage); сервер — дополнение, а не условие

## Известные грабли

- `cloud.js` сверяет `uid` с меткой владельца в localStorage — поэтому при переносе игроков
  сохраняются исходные id (`import_players`)
- Админ не удаляет сохранения (это ломает `reset_epoch`), только сбрасывает их действием
- Render (бесплатный тариф) — нет Shell: команды запускать через `build.sh` или локально с внешним `DATABASE_URL`
- `legacy_import.js` — временный (разовый перенос прогресса со старого домена), потом удалить вместе с `<script>` в `index.html`
