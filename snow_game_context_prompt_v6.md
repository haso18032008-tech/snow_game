## Проект игры
- `config/` — настройки (локаль и прод в одном файле), `urls.py`. `snow_game/` — единственное приложение: `models.py`, `views.py` (`clean_state()` чистит всё, что присылает клиент), `urls.py`, `admin.py`, команды `ensure_admin` и `import_players`, шаблон, статика, клиент игры (`static/snow_game/js/`: `config.js`, `state.js`, `game.js`, `render.js`, `ui.js`, `icons.js`, `audio.js`, `cloud.js`, `legacy_import.js` — временный).
- URL: `/`, `/ping/`, `/api/save/`, `/api/leaderboard/`, `/api/leaderboard/<id>/`, `/accounts/...` (allauth), `/admin/`.
- Аккаунты: allauth, логин/пароль без email + Google (переменные `GOOGLE_CLIENT_ID`/`GOOGLE_CLIENT_SECRET`, **не настроен**). Без входа игра идёт только в `localStorage`.
- Переменные окружения (значения не хранить в чате): `DJANGO_SECRET_KEY`, `DJANGO_DEBUG=False`, `DATABASE_URL`, `DJANGO_ALLOWED_HOSTS`, `GAME_ADMIN_USERNAME`, `GAME_ADMIN_PASSWORD`, `FINSTAT_URL`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`.
- `build.sh`: `pip install`, `collectstatic`, `migrate`, `ensure_admin`; Build Command на Render — `bash build.sh`.

## Что добавлено в игру 26.11.2026 (заливка **не подтверждена**, архивы `snow_game_jungle.zip`, `_v2`, `_v3`)
Подробности — в `CLAUDE.md`, раздел «Джунгли, дробовик, Грустити, железная дорога».
- **Грустити** (море, гарпун, награда — рыба), **джунгли** на севере за стеной (топор «ур. 28»): низкие пальмы, обезьяны, горилла, «Любопытстити»; лавки «Пальмовое дерево» и «Бананы»; бананы лечат.
- **Дробовик** (`gun`, `gdmg`, `grate`, `gcount`) кружит и стреляет сам, вместе с топором. **Охотники с мачете** (`jhire`, `jhdmg`) рубят обезьян, бананы сразу идут на лавку.
- **Железная дорога** (`rail`: Дрезина/Поезд/Метро; станции `railf`, `railj`). Станция стоит рядом с плиткой; выбор: встать → отпустить джойстик → нажать → вести в область → поехать только после отпускания; отпустить в центре или «Отмена» — остаться.
- **Магнит на корабле** растёт со скоростью корабля. Камера: `SG.CAM = { pitch: 52, fov: 33, dist: 72 }` (мои настройки, не откатывать).
- **Стрелка у ног** по биомам: основная жёлтая, море голубая, джунгли оранжевая. **Возрождение** — на базе биома смерти (если там база построена).
- **База в джунглях растёт** (`jup`, ур. 0–4): ограда, лечение внутри, цены лавок +20%/ур., покупатели чаще, лимит охотников 2+2·L.
- **Мир расширен на север** до `z = -300` (джунгли ~180 м глубиной); новые гиганты добавлены в конец `G.giants`, индексы `S.cut` не сдвинуты. Пальм 1100, обезьян 32, горилл 6.
- Ключи сохранения: `banana`, `stall.jwood`, `stall.banana`, `lv.jup/jhire/jhdmg`, stats `monk curio grust palms banana soldjwood soldbanana rides hmonk` (сервер обновлён).
- Баланс стартовый: джунглевая база 600K, дробовик 400K, охотник 40K×1.55^L, `jup` 300K×2.4^L, дорога 500K×2.5^L, станции 120K. Числа — в `config.js` и `KINDS` в `game.js`.
- Не проверено глазами: отрисовка (пальмы, охотники, станции, ограда, стрелки), выбор направления на телефоне, производительность с 1100 пальмами и 39 мобами джунглей на слабых телефонах.

## Что осталось (по порядку)
1. **Залить `snow_game_jungle.zip`**, проверить на Render. Также залить раздел «Наши проекты» (`snow_game_changes.zip`) и задать `FINSTAT_URL` — статус не подтверждён.
2. **Подкрутить по результатам игры:** баланс цен, вид моделей, удобство выбора направления на дороге.
3. **Фаза 2 в Финстате** (когда игра стабильна): удалить папку `snow_game/`; убрать `"snow_game"` из `INSTALLED_APPS` и `include("snow_game.urls")` из `config/urls.py`; добавить в `core/urls.py` `path("snow-game/", views.snow_game_bridge, name="snow_game")` перед `sw.js`. Файлы `config/settings.py` и `config/urls.py` в Финстате с CRLF — сохранять. Таблицу `snow_game_gamesave` оставить как резерв.
4. **После переезда:** удалить `legacy_import.js` и его `<script>` из `index.html`, убрать страницу-мост.
5. **Лимит Render Free: 750 ч/мес на воркспейс.** Финстат с пингером круглосуточно ≈ весь лимит; игра добавляет часы. Проверить Billing. Варианты: Starter для игры (~$7, оплата из Беларуси затруднена), «будильник» из Финстата вместо пингера (уже есть).
6. **Свой домен** `snow-game.com` / `snowgame.com`: оплата через знакомого в Польше. Подключение: Render → Custom Domains → DNS → Verify; затем обновить `DJANGO_ALLOWED_HOSTS`, `SNOW_GAME_URL`, `FINSTAT_URL`, redirect URI в Google.
7. **Google-вход:** OAuth-клиент в Google Cloud, redirect URI `https://<домен>/accounts/google/login/callback/`, переменные окружения. Нужен публичный домен.
8. **Доработки панели** (по желанию): графики по часам/неделям, экспорт CSV, фильтры по биомам/прогрессу, журнал входов. Базовая панель уже есть.
9. **Оптимизации игры** (по желанию): сборщик (Vite/esbuild), интервал сохранения 30 с, кеш рейтинга, throttle на `api_save`, серверная проверка правдоподобия `earned`, свой service worker (PWA).
10. **Локально у Финстата сломана `venv`:** `rmdir /s /q venv`, `python -m venv venv`, активация, `python -m pip install -r requirements.txt`; проверить, что `venv/` в `.gitignore`.

## Грабли, на которые уже наступали
- Neon в cmd: `set "DATABASE_URL=..."` — кавычки вокруг всего присваивания, без угловых скобок; после работы `set DATABASE_URL=`. Если Postgres ругается на `channel_binding`, убрать `&channel_binding=require`. Использовать `python -m pip`, не `pip`.
- `import_players` сохраняет исходные id (`cloud.js` сверяет `uid` с меткой владельца в `localStorage`). Повторный запуск безопасен.
- До первого импорта в новой игре никого не регистрировать.
- `localStorage` привязан к домену: при смене адреса прогресс незарегистрированных игроков пропадает без моста.
- HSTS на неделю; за прокси включён `SECURE_PROXY_SSL_HEADER`; Git на Windows не сохраняет флаг исполняемости `build.sh`.
- Индексы гигантских деревьев (`S.cut`) стабильны только если новые гиганты добавляются **после** существующих — не менять порядок генерации.
- Сервер ограничивает `lv`, `stats`, `prog` до 80 ключей: при добавлении улучшений следить за лимитом (сейчас `lv` ≈ 54).
